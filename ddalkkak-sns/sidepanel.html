로그인해 둔 Gemini·ChatGPT·Claude 화면에서 글과 이미지를 만들고, 게시는 직접 누릅니다.

🔑 이용권 · 라이선스

🔒 이용권 상태를 확인하는 중입니다.

발급받으신 라이선스 키를 입력 후 확인을 누르세요.

비워 두면 로컬 모드로 동작하며 아무것도 차단하지 않습니다. 서버를 지정하면 VERIFY_KEY · CLAIM_REWARD · VERIFY_MEMBERSHIP 요청으로 이용권을 확인합니다.

연결 상태

현재 연결된 네이버 블로그·카페·티스토리·Blogger·SNS 글쓰기 페이지를 확인하는 중입니다.

내 사진으로 글쓰기

사진을 올리고 메모를 적으면 AI가 사진을 분석해 사진 위치까지 정해 글을 씁니다. 게시는 직접 누릅니다.

사진과 내용을 준비하면 글을 작성할 수 있습니다.

초안 입력

주제를 직접 입력하거나, 네이버 블로그 상위 노출 글을 참고해 새 원고를 만듭니다.

선택한 검색 결과의 제목 패턴, 검색 의도, 자주 다루는 포인트를 참고해 새 초안을 만듭니다.

500~10,000자 · 목표 글자 수의 ±10% 범위로 작성합니다.

소제목, 강조 상자와 링크에 적용됩니다.

임시채팅을 찾지 못하면 일반 새 채팅으로 이어집니다. ChatGPT 이미지 생성은 GPT 기록에 남을 수 있습니다.

💡 아주 쉬운 사용법 가이드

          
        

        
    
          
  1. AI 로그인
    Gemini·ChatGPT·Claude 중 사용할 사이트에 본인 계정으로 로그인합니다.
    2. 
          
  2. 글쓰기창 열기
    지원되는 블로그·SNS 글쓰기 페이지를 띄운 뒤 ‘① 현재 탭 연결하기’를 누릅니다.
    3. 
          
  3. 주제 입력
    주제만 적어도 되고, 필요하면 대상 독자·키워드·요청사항을 추가합니다.
    4. 
          
  4. 초안 작성
    ‘② 초안 작성’을 누르면 AI가 JSON 초안을 만들고 미리보기에 표시됩니다.
    5. 
          
  5. 수정
    수정 요청을 적고 ‘수정 요청 반영’을 누르면 초안이 다시 작성됩니다.
    6. 
          
  6. 이미지
    ‘③ 자동 이미지 생성’으로 본문 이미지를 만듭니다. 마음에 들지 않으면 개별 삭제 후 다시 생성하세요.
    7. 
          
  7. 최종 입력
    ‘④ 연결된 글쓰기창에 넣기’를 누르면 제목·본문·태그·이미지가 입력됩니다. 게시는 직접 누릅니다.
